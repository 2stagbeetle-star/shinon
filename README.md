# 心音 SHIN-ON

スマホを横にして遊ぶ、無料のホラーアドベンチャー（PC でも遊べます。ヘッドホン推奨）。

閉校した中学校に閉じ込められた新人警察官・真壁悠。見えない殺人鬼から、心拍だけを頼りに隠れ、逃げる。

> 子どもの誘拐と死・いじめ・殺人・監禁・遺体を扱う物語です。直接の描写は避けています。

## 遊び方

https://2stagbeetle-star.github.io/shinon/ を開くだけです。

- **アプリとして入れる：** Android はタイトル画面の「アプリとして入れる」から。iPhone は Safari の共有ボタン →「ホーム画面に追加」から。全画面・横向きで起動します。
- 一度読み込んだ絵・声・動画は、電波がなくても再生できます。
